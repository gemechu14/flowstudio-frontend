FlowStudio Frontend
===================

**FlowStudio** (package ``crestward-platform``) is the Crestward Labs web UI for
building and operating agentic workflows: tools, agents, data sources, visual
workflow graphs, messaging channels, community tools, and platform settings.

This documentation covers **this frontend codebase only** (Vite + React SPA).
It does not document the backend API implementation beyond the HTTP endpoints
the UI actually calls.

Live application: https://flowstudio.crestwardlabs.com/workflows/
